## 🚀 Overview

A modern, performant portfolio website showcasing my journey as a Site Reliability Engineer. Built with a focus on simplicity, speed, and accessibility - the same principles I apply to production systems.

**Live Site:** [ragulmk1.github.io/portfolio](https://ragulmk1.github.io/portfolio)

## ✨ Features

- **Zero Dependencies** - Pure HTML, CSS, and vanilla JavaScript
- **Lightning Fast** - No images, no frameworks, instant load times
- **Fully Responsive** - Perfect on mobile, tablet, and desktop
- **Dark Theme** - Monitoring dashboard aesthetic inspired by Grafana
- **Accessible** - Semantic HTML5, proper ARIA labels, keyboard navigation
- **SEO Optimized** - Meta tags, structured data, performance focused

## 🎨 Design Philosophy

The design reflects my identity as an SRE:

- **Monitoring Dashboard Aesthetic** - Dark theme inspired by Grafana/Prometheus
- **Cyan Accents (#66FCF1)** - Represents "healthy" metrics in monitoring systems
- **Terminal Typography** - JetBrains Mono for that command-line feel
- **Minimal & Functional** - Every element serves a purpose

## 🛠️ Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern Grid & Flexbox layouts, CSS Variables, smooth animations
- **JavaScript** - Vanilla JS for interactions, Intersection Observer API
- **Fonts** - Inter (UI), JetBrains Mono (code/accents)

## 🚦 Getting Started

### Prerequisites

- A modern web browser
- Git installed
- (Optional) A local web server for development

### Local Development

```bash
# Clone the repository
git clone https://github.com/Ragulmk1/portfolio.git

# Navigate to directory
cd portfolio

# Option 1: Open directly in browser
open index.html

# Option 2: Use Python's built-in server
python -m http.server 8000
# Visit http://localhost:8000

# Option 3: Use Node's http-server
npx http-server -p 8000
```

## 🔧 Customization

The portfolio uses CSS variables for easy theming:

```css
:root {
    --bg-primary: #0B0C10;      /* Deep space black */
    --accent-cyan: #66FCF1;      /* Cyan accent */
    --accent-blue: #45A29E;      /* Blue accent */
    --text-primary: #E8E9EB;     /* Primary text */
    /* ... more variables */
}
```

To customize colors, simply update these variables in the `<style>` section.
